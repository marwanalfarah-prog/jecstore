{# The wishlist heart, drawn in the state it is actually in (Part I §14). This is a toggle, and it used to render identically whether the product was saved or not — same outline heart, same "Add to wishlist" label, on a product already on the list. A shopper had no way to tell, and a second click silently removed the thing they thought they were adding. So the button reports its own state three ways, because one is never enough: a filled heart (glanceable), a changed label (readable), and `aria-pressed` (announced by a screen reader, §17.7). The id is what lets the POST swap this very button back in, so pressing it updates the control as well as the header badge rather than leaving a stale label behind.
