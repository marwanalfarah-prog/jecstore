{# Star ratings (Part I §14). Rendered as a fixed row of five outlines with a filled row clipped over the top, rather than as five separate icons chosen by comparison. That way a 3.5 is drawn as three-and-a-half stars instead of being rounded to something the number beside it contradicts. The clip runs from the inline start, so it fills right-to-left in Arabic without a second implementation (§17.3). #} {% macro _row(class) -%} {%- for _ in range(5) -%} {%- endfor -%} {%- endmacro %} {# `value` is 0–5 and may be fractional. `size` is any Tailwind height. #} {% macro rating(value, size="h-4") %} {{ _row("absolute inset-0 flex text-star-empty fill-current") }} {{ _row("flex h-full text-star fill-current") }} {% endmacro %} {# The whole line: stars, the number, and how many people said so. #} {% macro summary(rating_summary, t, num, size="h-4") %} {% if rating_summary.has_reviews %} {{ rating(rating_summary.average, size) }} {{ num(rating_summary.average, decimals=1) }} ({{ num(rating_summary.count) }}) {% else %} {{ rating(0, size) }} {{ t("product.no_reviews_yet") }} {% endif %} {% endmacro %}
